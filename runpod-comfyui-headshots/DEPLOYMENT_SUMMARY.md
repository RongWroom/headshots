## Configuration Requirements

### Required Before Deployment

1. **Docker Registry Account**
   - Docker Hub username
   - Logged in via `docker login`

2. **RunPod Account**
   - Account created at https://www.runpod.io
   - Billing configured
   - API key generated

3. **DanDan LoRA Model**
   - Model trained and uploaded to accessible storage
   - Public URL available

4. **Webhook Secret**
   - Generated via `openssl rand -hex 32`
   - Or auto-generated by deployment script

### Environment Variables to Set

**In RunPod Endpoint:**
```
WEBHOOK_SECRET=<your-secret>
DANDAN_LORA_URL=<your-lora-url>
COMFYUI_PATH=/workspace/ComfyUI
PYTHONPATH=/workspace/ComfyUI
```

**In Your Application (.env.local):**
```
RUNPOD_ENDPOINT_ID=<your-endpoint-id>
RUNPOD_API_KEY=<your-api-key>
RUNPOD_WEBHOOK_SECRET=<your-secret>
```

## Troubleshooting Guide

### Common Issues

**1. Endpoint Not Starting**
- Check Docker image exists and is accessible
- Verify image name is correct in RunPod settings
- Review RunPod logs for errors

**2. Out of Memory**
- Reduce image resolution in workflow
- Use A100 GPU (more VRAM)
- Optimize ComfyUI workflow

**3. Slow Generation**
- Check network latency for image downloads
- Optimize workflow (remove unnecessary nodes)
- Consider faster GPU (A100)

**4. LoRA Not Loading**
- Verify `DANDAN_LORA_URL` environment variable
- Check LoRA file is accessible
- Ensure file format is `.safetensors`

**5. Webhook Not Received**
- Verify webhook URL is publicly accessible
- Check webhook signature validation
- Review application logs

See `DEPLOYMENT_GUIDE.md` for detailed troubleshooting.
